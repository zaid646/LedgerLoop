- prompted 7B — Qwen2.5-7B-Instruct zero-shot, given the 13-label list, no retrieval
- 7B + RAG    — same 7B, prompt augmented with lexical candidates from the merchant KB

## latency/cost note
The vLLM-served 7B is FASTER per call than the naive transformers.generate() 0.5B
path here, because vLLM does continuous batching + paged attention on the same GPU.
In this harness the 0.5B's win is memory footprint / co-tenancy / no retrieval
index, not raw latency — serving stack dominates, not parameter count.
