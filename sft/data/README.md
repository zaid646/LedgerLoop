# SFT data

Generated by `python sft/format_dataset.py`.

| File | Description |
|---|---|
| `public_dolly_sample.jsonl` | 320 no-context examples sampled from `databricks/databricks-dolly-15k` (CC BY-SA 3.0). |
| `train.jsonl` | 327 records: 152 LedgerLoop + 175 Dolly. |
| `val.jsonl` | 55 records: 30 LedgerLoop + 25 Dolly. |
| `summary.json` | Counts, sources, category list, seed and format metadata. |

Each JSONL row has `id`, `source`, `category`, `instruction`, `response`, `prompt`,
`completion` and `text`. The `text` field is the Qwen ChatML rendering consumed by
`trl.SFTTrainer`; `prompt`/`completion` are used by the evaluator and are suitable for
prompt-completion training.

The LedgerLoop rows are generated by `sft/domain_data.py`, not collected from customers.
Dolly attribution: Databricks, *databricks-dolly-15k*, CC BY-SA 3.0,
<https://huggingface.co/datasets/databricks/databricks-dolly-15k>.
